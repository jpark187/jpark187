## Selected Projects

**[Multimodal HM-MRI & Pathology Learning for Prostate Cancer](https://github.com/jpark187)** *(UChicago Capstone)*
A pathology-guided virtual biopsy framework that trains on paired Hybrid Multidimensional MRI and histopathology data, then deploys on MRI alone at inference. The system predicts cancer presence, lesion-level Gleason Grade Group, and identifies the dominant tumor driving treatment — mimicking what a radiologist and pathologist together would tell a urologist. Built with a teacher–student distillation architecture (QLoRA) over a ~500-patient UChicago cohort.

**[AI Sentiment Analysis — 200K News Articles](https://github.com/jpark187/Natural-Language-Processing-Project)**
Analyzed a corpus of 200,000 news articles on AI and data science to identify which industries and firms face the greatest AI exposure, by what means, and what drives successful adoption. Pipeline included article filtering, topic modeling, entity extraction, and a custom sentiment analysis model.

**[Financial Analysis Chatbot](https://github.com/jpark187/Financial-Analysis-Chatbot/tree/main)**
Built a personal finance tool using a relational MySQL database of financial transactions dating back to senior year of college. Connected an open-source LLM (via Ollama) to a chat interface so users can ask natural language questions about their spending habits — all run locally to ensure data privacy.

**[CTA Q&A Chatbot](https://github.com/jpark187/CTA-Q-A-Chatbot)**
RAG pipeline built on web-scraped CTA data with open-source AI models for response generation. Evaluated with RAGAS metrics: Faithfulness 0.942 · Context Precision 0.931 · Context Recall 0.867 · Context Relevance 0.854.
